## Data and code availability

The complete rule registry, source locators, frozen validation protocols, gold
identities, evaluation manifests, analysis scripts, and implementation used to
reproduce the reported analyses are publicly available at
<https://github.com/PaiLotien/visconcord>, release `v1.0.0` (commit
`432df91ac6a38045f4bf6ea39dc7d81b1c4248d6`). The source code is provided under the MIT License. Original
project data and documentation are provided under CC BY 4.0 where the authors
hold the relevant rights; UCI-derived and other third-party materials remain
subject to their original licenses and attribution requirements. The package
includes 120 validation contexts, 140 candidates, 360 saved validator replays,
and the adjudicated labels used for the reported component-level validation.
